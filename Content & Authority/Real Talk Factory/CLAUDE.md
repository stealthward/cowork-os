# Real Talk Factory

## Project Identity

This project covers the launch build-out of The Factory — the video content show with Brett Ward, Danny Davis, and Valli Lopez. The goal is to get the show fully operational: brand, production standards, platform presence, operations, and distribution all defined and running. This project lives inside the Content & Authority workstation and ends when all Asana tasks are complete. When archived, everything learned carries forward into the workstation.

Asana project: https://app.asana.com/1/459051476492004/project/1214560093184793

## Workflow

1. Check current Asana task status before any project session
2. Work through tasks by section: Design → Production → Operations → Marketing
3. For decisions made (set design, frequency, asset delivery, etc.), log them in MEMORY.md immediately
4. Any copy or content produced (podcast description, webpage copy) runs through voice-principles.md first
5. Flag completed tasks in MEMORY.md — do not rely on Asana alone for project status within Cowork

## Project Rules

- This project was cloned from the Rebuild Asana project. Any task notes referencing "REbuild" branding or the REbuild brief are carryover and should be ignored or updated.
- The Factory is video-first. It is not a podcast in the traditional sense. Segments run up to 10-12 minutes. Reels are cut from each episode.
- Decisions made here feed the parent workstation (Content & Authority). Once this project closes, the show's SOPs, brand standards, and production rhythm live there permanently.
- All copy (descriptions, webpage, social) follows Brett's voice principles and content frameworks.
- The episode roadmap is a guideline, not a spec. It gets revised weekly to mold around the talking points most relevant to the hosts, within the show framework. When a session deliverable and the roadmap differ, the current week's talking points take precedence. Do not flag roadmap deviations as conflicts.
