# Branding Blueprint: discovery summary template

_Shared reference for the Branding Blueprint skills. Not a skill; it never loads on its own. Built 2026-11-03 with the blueprint entry skill. Copy into `<client folder>/discovery-summary.md`. Shared Core candidate._

The discovery summary is Brett's record of the discovery meeting. The CMO drafts it from Brett's dictation or the Plaud recording; it becomes the summary only when Brett approves it. Every row carries its source: "meeting <mm:ss>" with the agent's words quoted where they set a fact, "Brett's dictation, <section>" for his notes, "Brett" for something he added, or "not covered". Anything Brett marks as his best guess keeps that label. Not covered is allowed; filled in is not.

## Agenda coverage

Every prompt in `discovery-agenda.md` that the meeting did not answer, listed by section. An unanswered core input (C1 to C6) blocks blueprint-strategy until Brett answers it or asks the client.

## Brett's notes

Anything Brett wants the Blueprint to reflect that the agent did not say (his read of the agent, relationship history, sensitivities). Labeled as Brett's judgment.
