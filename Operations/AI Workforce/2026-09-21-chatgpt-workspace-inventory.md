## What this changes

- **Two skills, not one.** Client-asset captions (LIL, MM, List Kit, client show socials) and RTM-promotional captions (podcast promotion, products and services, agent influencer) are different jobs with different voices. Recommendation stands: `captions` and `rtm-social`, sharing the checklist and the voice file. Pending Brett.
- **The three RTM social projects are one skill with three modes.** Two of them share the same base text word for word. The third adds a sandwich format. One skill file with a tone rule and three output shapes replaces all three.
- **Titles are a standing output.** Thumbnail headlines, full-episode headlines, and episode title variations appear in five projects. The captions skill gets a titles mode with three options; rtm-social keeps its five-title block.
- **Image quotes are a pattern with no rules.** Two projects pull five direct quotes from a transcript for the designers. A small sidekick or a mode on podcast-prep, later.
- **List Kit is a product line the roster does not know about.** Twenty chats, agent by agent. It goes into the captions skill as a mode (property description in two-line sections, three copy variations, just-sold version) and into the production flow map as a fourth content line to verify with Elizabeth.
- **Shared memory is on everywhere.** Seventeen projects, all on default memory, one login. Any team member's chat can bleed into any other's output. Turning memory to project-only in the four caption projects is a five-minute fix for Elizabeth that helps before the migration. The Claude version carries its context in files, so the problem does not travel.
- **Instructions were never versioned.** One field per project, no history, one of them still carrying ChatGPT's own preamble. The exported copies in assets/chatgpt/ are the first version control these rules have had.
- **Sources are thin.** Four items across seventeen projects, none in the caption projects that run weekly. The team's working knowledge is in prompts and heads, not files. This matches Elizabeth's answer that SOPs are still being consolidated.
