## WhatsApp Drafting Conventions

1. **One beat per bubble.** Break replies into separate messages by conversational beat: greeting, direct answer, supporting context, logistics, closer. Never draft one continuous block when several short bubbles would feel more natural. Separate each bubble with a blank line and a bold label (`**Bubble 1**`, `**Bubble 2**`) so you can copy each message individually.
2. **Bubble labels are not message text.** The bold `Bubble` labels are copy guides for you, not part of the message. Keep the actual text underneath each label clean and ready to paste.
3. **Quote-reply when responding to a specific point.** When answering one message in a multi-message thread, deflecting a compliment, or responding to a specific question, note that you should use WhatsApp's reply feature. Put a bracketed note before the relevant bubble: `[Reply to [NAME]'s message: "short excerpt"]`.
4. **Keep bubbles short.** A normal bubble is one short paragraph, usually one or two sentences. If a message needs more context, split it into several bubbles instead of one dense paragraph.
5. **Use plain text unless formatting changes the outcome.** WhatsApp can render asterisks as bold, but default to plain text. Use emphasis only when the recipient must notice a key ask, date, amount, or decision. Don't use email-style section headers unless the message carries multiple distinct topics and structure genuinely helps.
6. **Use emoji for warmth, not decoration.** One emoji per bubble maximum, and only when it adds warmth, sincerity, or a natural reaction. Match the recipient and the thread. Don't stack emojis, use them as filler, or add them to serious business terms.
7. **Stay casual without opening loops.** WhatsApp tempts extra friendliness, but the cross-channel guardrails still apply: don't offer follow-up work, invite revisions, promise speed, or create new obligations unless you explicitly ask for it.
8. **No email artifacts.** Don't include a subject line, a signature block, "Best Regards," or a formal sign-off. A simple "Thanks!" or a casual closer is enough when the thread needs one.

## Draft Output Format

Use this format when presenting WhatsApp drafts:

```markdown
[Reply to [NAME]'s message: "short excerpt"]

**Bubble 1**
Message text you can paste.

**Bubble 2**
Message text you can paste.
```

Omit the bracketed reply note when you shouldn't use the reply feature. Omit extra bubbles when the reply only needs one message.
