# Source PDFs

_This folder holds reference PDFs you own (guides, manuals, reports) that you want your workspace to learn from. It ships with one example already inside, Jeff's own "PARA for Google Drive" guide, so you can test the extract pattern with a real source. Anything you add after that is your own and stays on your machine._

**The pattern: extract, do not load the whole PDF.** A full PDF is large and slow to read every time. Instead, ask Cowork to pull the reusable parts out of a PDF and write them into a short markdown reference file one level up from `Source PDFs/`. Root-level frameworks go in `00_Reference/`; workstation- or project-specific extracts go in that workstation or project's Resources folder. Then point future work at the markdown file, not the original PDF.

**How to use it:**

1. Drop a PDF you own into this folder.
2. Ask Cowork: "Can you turn the reusable parts of [PDF name] into a short markdown reference file and show me where it should live?"
3. Cowork writes a short `.md` summary: the frameworks, rules, and examples worth reusing.
4. Reference that summary from the workstations that need it.

Keep original PDFs here for your own lookups. PDFs you add after installation stay on your machine and should not be shared unless you have the rights to redistribute them; the bundled PARA guide is the course example that ships with this template.
