# Lesson 5.02: Project Lifecycle Prompts

_Use these prompts in order as you follow Lesson 5.02. Replace the example career details when you apply the same project lifecycle to your own work._

## 1. Connect Career HQ To The Workspace

```text
I added a new workstation called Career HQ. Read its CLAUDE.md and MEMORY.md, then propose updates to all the relevant surfaces in our workspace so anything about my long-term career materials and job opportunities routes here.
```

## 2. Create The Job Search Project

```text
Inside Career HQ, create a Job Search PMM Roles project. The goal is to land a full-time Product Marketing Manager role. Follow project creation rules and conventions.
```

## 3. Create The Application Tracker

```text
Your task is to create an application tracker in Excel format for my job search project. You can find my resume in the workstation resources folder and the job openings I'm applying to in the project resources folder. Add these columns to start with: Company, Role, Fit, Status, Next Step, Notes, and Source File.
```

## 4. Tailor The Resume

```text
Your task is to review and analyze the Google PMM JD in detail and recommend improvements to my resume so that the resume is specifically tailored for the role. Summarize the 3 most important responsibilities of the role, propose 5 bullet point edits, and output every change in a two-column Original versus Updated table.
```

After reviewing the recommendations, continue with:

```text
I agree with all your recommendations, create a role-specific resume with these updates following the original format, rename it and save it within the project resources folder.
```

## 5. Update The Project

```text
Quick update for the job search project: Google gave me a first-round interview, I’ve applied to Duolingo but they haven’t replied, and LinkedIn straight up rejected me. Update the tracker.
```

## 6. Prepare For The Interview

Attach `Interview Prep - CARL Framework.md`, then paste:

```text
Help me prepare for the upcoming Google interview. Analyze the Google PMM JD and infer the 5 behavioral questions this role is most likely to test.

Use my resume and the attached CARL interview framework to draft a recommended answer for each question, and save the CARL framework to the appropriate resources folder.
```

## 7. Update Memory And The Tracker Directly

```text
Duolingo replied and sent me an online assessment. Update the project memory and application tracker.
```

## 8. Update Memory At The End Of A Session

```text
I’m done with this session. Identify all workstations and projects we worked on today and update the relevant memory files accordingly.
```

## 9. Complete And Archive The Project

```text
The job search project is done, I got the job at Google. Go through the project completion workflow and walk me through what you did.
```
