# Daily AI Diary — the casual version (just dictate something like this)

I want to be more on top of the big decisions and learnings and insights that I'm gathering day to day, and I want to build a daily AI diary. Basically a little window that pops up on my computer once a day, like at 5pm, asks me how my day went, I type a few sentences, hit save, and it goes away until tomorrow. Every entry should save as its own little text file named by the date, like 2026-12-31.md, all in one folder on my machine. No database, no cloud, no accounts, just text files I own and could feed back to an AI later. Keep the whole thing really simple, like one HTML file plus whatever my computer uses to schedule stuff so it pops up on its own every day, even after I restart. If I skip a day don't break or guilt trip me, and if I open it twice in one day just update that day's file instead of making a duplicate. A streak counter would be fun. I'm not an engineer, so before you build anything, tell me the plan in plain English, where the files will live and how the popup gets triggered, and then build it and actually test that the schedule fires. Oh, and I heard that on a Mac, scheduled scripts often can't touch the Desktop or Documents folders because of privacy settings, so put the diary folder somewhere they can actually reach.
