## How to read a course against this OS

1. Most courses assume a terminal and a single operator. Translate every terminal step to the desktop app Code tab before judging it; if it cannot be done there, defer it.
2. Most courses do not separate shared from personal. Anything that puts personal context in a shared file is rejected on that basis alone.
3. Prefer what improves a layer we already have over what replaces it. The knowledge layer (CLAUDE.md, MEMORY.md, routing) is built and working.
