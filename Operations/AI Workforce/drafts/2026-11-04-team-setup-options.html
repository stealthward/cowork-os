The setup in one paragraph

Keep the shared kit in one private GitHub repo that Claude syncs to every member automatically, so a fix you approve reaches everyone with no copying and nobody else needs GitHub. 6. The workforce's own identity

Today every agent reply in Asana posts as you. Asana's developer docs recommend a separate user as the bot, named so people can tell an app is acting. Claude in Slack expects the same thing: an address like claude@ added to each tool as a member, with the narrowest role.

Recommend one workforce account (a company email address, an Asana seat, read-only where a tool allows), used by the cloud tasks now and by Slack later if you add it. Asana Starter is $10.99/user/mo annual or $13.49 monthly; above 5 users Asana sells seats in blocks of 5, so the cost depends on open seats on your current plan, which I have not read. A Google Workspace licence may be needed for the email address; not checked.

Sources: Asana authentication, asana.com/pricing
