Cloud-Only Feasibility

Every part of the OS that depends on the office PC, mapped to a cloud path or a blocker. Researched from current Anthropic, GitHub, and vendor docs on 11/5. Nothing is moved or bought.

Verdict

About 90% of the OS can run in the cloud now. The seats, workers, skills, memory files, and every connector (Asana, Zoho, Smartsheet, Gmail, Drive, Calendar) work in Claude Code cloud sessions run from a private GitHub repo. Scheduled tasks become cloud routines that run with every computer off.

What can't go fully cloud today is work that needs a browser signed in as you. Anthropic documents no cloud browser that holds your logins. That work stops depending on the office PC, but it still needs a computer with Chrome, any computer, through Claude in Chrome.

What changes in your day

  • You open a session from the Claude desktop app, claude.ai/code, or the phone app, on any computer, and pick your OS repo. Same seats, same phrases, same files.
  • Each session works on a fresh copy of the repo and saves its changes back to GitHub. Memory and logs land on the main copy without you merging anything, if the repo allows Claude to push directly (to be tested).
  • Nothing local is needed except a browser. The office PC becomes just another computer.

Unproven, test before relying on it

  • Claude pushing memory and log changes straight to the main copy. The docs say a GitHub rule decides this; whether it behaves as described is untested.
  • Two sessions changing the same file at once. Not documented; the safe rule is one session at a time on shared files such as MEMORY.md.
  • Publishing Artifacts (the registry page, review pages) from a cloud session. Not researched yet.
  • LibreOffice output matching the Word-built cut sheets.

Where it lives

Your OS goes in its own private repo under your personal account, separate from the team kit repo. That fits account scenario A: you stay on your personal plan, which also has Claude Projects (cloud threads that read Drive folders and a MEMORY.md), a feature not yet offered on Team. GitHub states it does not train AI on private repo content. GitHub Free covers it ($0).

Recommendation

Go cloud-first, and prove it with a one-week test before moving anything for real. The test copies the OS, without Max Income and apriliapeace, into a private repo and runs your normal week from cloud sessions. Your local folder stays the live copy until the test passes.

  1. You: create a GitHub account if you don't have one, and install the Claude GitHub app on one private repo (your consent clicks).
  2. COO: loads the copy, fixes the hook paths, sets the direct-push rule, and moves morning-inbox-triage to a routine.
  3. You: run a chief of staff daily, one COO job, and one CMO draft from the cloud, on two different computers.
  4. COO: tests one cut sheet with Plaud timings and LibreOffice, and one Artifact publish.
  5. Pass when all of those work with the office PC off, and memory updates landed without a merge. Then you decide where Max Income goes, and the local folder retires.
