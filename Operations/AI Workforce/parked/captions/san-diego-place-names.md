## Abbreviations

Spell these out in a caption. Keep the abbreviation only when the agent uses it as a brand (for example a team named after it).

| Abbreviation | Means |
|---|---|
| RSF | Rancho Santa Fe |
| PQ | Rancho Peñasquitos |
| RB | Rancho Bernardo |
| PB | Pacific Beach |
| OB | Ocean Beach |
| MB | Mission Beach |
| IB | Imperial Beach |
| UTC | University Towne Centre (the mall and the area around it) |
| UC | University City |
| CV | Ambiguous: Carmel Valley or Chula Vista. Read the transcript for which, then spell it out |
| North County | Keep as written; it is a region, not an abbreviation |
| East County, South Bay | Keep as written |
| SD | San Diego |
| DTSD | Downtown San Diego |
