# 🖥️ Using the Dashboard

The dashboard files your finance documents for you. You drop a file in exactly as you received it, and it reads the document, names it correctly, and puts it in the right folder. You look the result over and confirm. That is the whole job.

One idea runs underneath everything: **the dashboard reads the document, not the file name.** A file called "CBT.pdf" and a file called "June statement final v2.pdf" get the same treatment, because the name is ignored and the contents are read. When it cannot tell what something is, it says so and refuses to file it rather than guessing. A clear "I don't know" is always better than a confident wrong answer.

The naming convention, the account list, and the folder map live in the **Filing system** section of this doc. This guide covers the screens themselves. There are three tabs across the top: **File a document**, **Quality control**, and **Settings**.

## File a document

This is where you spend almost all of your time. Drop in a single file or a whole month's worth at once.

Each file becomes a **card**. The card shows three things: the name the file will get, the folder it will go to, and what the dashboard matched on to decide, such as the account on a statement or the payee on an invoice. Nothing has moved yet. The card is a preview.

**File all.** Once the cards look right, one click files everything together. Bank and card statements land in their folder and get their shortcut in folder 04 in the same action, so a statement is never filed twice.

**When it doesn't recognize a company.** If an invoice comes from a payee the dashboard hasn't seen, the card offers **Add vendor and use it**. One click teaches it that payee for good, so you never have to fix it again.

**When a file already exists.** If you drop in a document whose name and folder already exist, the card stops and asks instead of quietly making a copy. **Replace existing** swaps the new file's contents into the one already there and keeps its history and its shortcut, which is what you want when a statement or report gets reissued. **Keep both** files the new one alongside the old. It never overwrites without asking, and "File all" leaves these for you to decide one at a time.

**When it can't identify something.** It refuses, tells you why, and never files under a guessed name. Spreadsheets are refused on sight, since they can't be read. Anything the dashboard won't take, you file by hand.

## Quality control

This tab is for checking and fixing, not daily filing. You will use it mostly at month end.

**Needs a name.** Any document the dashboard couldn't name on its own waits here. Each one has an **Identify** button that re-reads it and tries again.

**Check the folders.** Pick a folder and the dashboard reads every document in it, checks each one against its name, and flags anything named or filed wrong. Because it reads the documents themselves, it catches a file whose name looks right but whose contents don't, which a name-only check would miss. It is a good habit at month end, and it has caught real mistakes. The list only shows the current year and the year before, so there is nothing old to wade through. Each flagged file has a **Fix** button.

**Fix one file.** Paste the Drive link to a single document and the dashboard reads it, renames it, moves it to the right folder, and fixes its shortcut in 04. It shows you the change first and does nothing until you confirm. Use this when one file landed in the wrong place.

**System health.** This checks the dashboard's own setup for problems and offers to fix what it finds. Run it if something seems off.

**Recently filed.** A running list of what was filed lately, so you can confirm your work went where you expected.

## Settings

Most of this tab is setup you will rarely touch.

**Add a vendor.** Adds a payee by hand, the same thing the **Add vendor and use it** button does from a card.

**Filing rules.** A view of the rules that decide where each document type goes. This is reference, not something you change day to day.

**Setup and repair.** Maintenance tools, kept out of the way on purpose. **Organize Recs and Registers** tidies folder 04 and rebuilds any missing statement shortcuts. **Restore recommended settings** resets the filing rules to their standard setup. These are admin tools. Leave them alone unless Brett or the system asks you to run one.

## The short version

Drop the file in. Read the card. Confirm. The dashboard reads every document, refuses what it can't identify, and never guesses. When something looks off, the **Quality control** tab is where you check and fix it.
